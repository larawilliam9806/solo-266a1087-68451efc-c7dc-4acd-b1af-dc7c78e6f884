# 果园设备调查 · 答卷清洗

用于果园设备调查的答卷清洗网页：上传带户号的答卷 CSV 与 JSON 跳题表，系统按跳题规则推演每户路径，只保留走到题目上的答案；逐户改答；导入名册后按抽样位生成交卷清单并下载 CSV。

## 功能

- **导入**：CSV + JSON 跳题表，一次导入形成一个批次。CSV 自动识别户号列（`户号`、`household_no` 等，找不到时用第一列），支持 UTF-8 / GBK。
- **跳题**：单选题的某个选项指定了跳转题号就跳到该题；该选项没有指定跳转就按题序进入下一题；遇到空答立即停止。
- **只采用走到题目的值**：被跳过、或在第一条空答之后的答案不会导入（即使 CSV 里填了值）。
- **交卷清单**：每批可导入一份名册 CSV，按抽样位列出实际入样户；每个抽样位只计一份答卷，主户答卷不合格时用候补（见下节）。
- **锁定与改答**：复核员可锁定/解锁所见到的入样户；锁定户仍可改答，改后合格就用新答案交卷，失去资格则拒绝保存并说明原因。
- **逐户改答**：按到达每题前经过的题目序列（路径）分别保存答案。两条路径走到同一道题（例如最后共用的费用题）时互不干扰；切回原路径即恢复该路径上填过的值。改答页会列出其他路径上已保存的答案供核对。
- **下载**：交卷清单 CSV 按抽样位列出入样户与当前路径上的有效答案，空位注明原因；另有全部分析用 CSV，含每户户号、当前路径、已答题数、每道题在当前路径上的有效答案、首个漏答题及题干。
- **保存失败回退**：一次保存是一个 SQLite 事务；失败时网页与下载都继续沿用上次保存的答卷，并提示错误。

## 名册与交卷清单

在批次页上传名册 CSV（每批只能成功导入一份），每行一个抽样位。示例见 `examples/roster.csv`：

```csv
抽样位,主户号,候补户号
S1,H001,
S2,H005,H004
S3,H006,H004
```

- **抽样位**与**主户号**各自唯一；户号须在本批答卷中；主户不能兼作候补。
- 候补户号可留空；同一候补可以登记在多个抽样位。
- 一个抽样位最终只计一份答卷，按以下顺序决定入样户：
  1. **已锁定户**先保留在该抽样位（即使其答案已不再合格）。
  2. 纳入**合格主户**。
  3. 剩余空位按名册顺序，使用**尚未入样的合格候补**。同一候补在多个抽样位登记时只会入样一次。
  4. 仍空着的抽样位注明原因（主户未答完/答案不在选项内、候补不合格、合格候补已在别处入样等）。
- **合格**指：当前路径走到最后一道题且每道题都有答案，路径上所有单选题的值都在该题选项内。
- 复核员可**锁定**页面上看到的入样户，或**解锁**。锁定时若该抽样位已经换户或空缺，操作被拒绝并提示刷新。
- 锁定的候补不会被后来答齐的主户顶替。
- 锁定户仍可改答：改动后仍合格则用新答案交卷；若改后失去资格（漏答或单选值不在选项内），保存被拒绝，网页和下载继续显示上次保存的答卷。
- 每次查看或下载，名册、锁定状态与答卷都取自同一个数据库快照，三者不会来自不同的已保存状态。

**合格**与锁定判断、清单推演集中在 `app/roster.py`，与数据库和框架无关，便于测试。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在命名卷 `survey-data`（容器内 `/data/survey.sqlite3`）。可用环境变量调整：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SURVEY_PORT` | `8000` | 宿主机端口 |
| `SURVEY_SECRET` | `change-me-in-production` | Flask session 密钥，请在生产环境修改 |
| `SURVEY_DB` | `/data/survey.sqlite3` | 容器内数据库路径 |

不用 Docker 也可以直接运行：

```bash
pip install -r requirements-dev.txt
cd app
SURVEY_DB=../data/survey.sqlite3 python3 -m main
```

## 答卷 CSV

第一行是表头，必须含户号列；其余每列是一道题。列名写成 `题号 题干`（如 `Q1 设备来源`）、只写题号、或只写题干都可以匹配到 JSON 里的题号。

```csv
户号,Q1 设备来源,Q2 自购设备类型,Q3 自购台数,Q4 是否享受购置补贴,Q5 租赁方式,Q6 租赁台数,Q7 年费用合计（元）
H001,自购,喷药机,2,无,,,12000
H002,租赁,喷药机,2,有,按年整租,3,8000
```

示例见 `examples/answers.csv`。户号重复时保留第一行并给出提示。

## JSON 跳题表

支持四种写法，任选其一。

1. 完整题目列表（顺序即题序）：

```json
[
  {"id": "Q1", "title": "设备来源", "type": "single",
   "options": ["自购", "租赁"], "jumps": {"租赁": "Q5"}},
  {"id": "Q2", "title": "年费用", "type": "number"}
]
```

2. `questions` 对象 / 数组，元素同上。

3. 跳题表 + 题序 + 元信息：

```json
{
  "order": ["Q1", "Q2", "Q3"],
  "titles":  {"Q1": "设备来源"},
  "types":   {"Q1": "single"},
  "options": {"Q1": ["自购", "租赁"]},
  "jumps":   {"Q1": {"租赁": "Q3"}}
}
```

4. 纯跳题表：顶层直接是 `{"Q1": {"租赁": "Q3"}}`。此时题序取 CSV 列顺序，单选题的选项可由 CSV 中出现的值补全。

规则：

- 跳转必须是**后面的题目**，目标题号必须存在，否则导入报错。
- 未在 `options` 中列出的跳转答案会自动补进选项。
- 跳题表里的题若没有对应 CSV 列，仍会出现在问卷中但没有导入答案（会有提示）。

示例见 `examples/jumps.json`。运行 `python3 -I examples/preview.py` 可预览示例的解析结果与每户路径。

## 路径与答案

答案的存储键是 `(路径, 题号)`，路径 = 到达该题之前经过的题目序列。

以示例问卷为例：

- 自购：`Q1 → Q2 → Q3 → Q4 → Q7`
- 租赁：`Q1 → Q5 → Q6 → Q7`

`Q7` 被两条路径共用，因此每户在两条路径上各有一份 `Q7` 答案：

- 在租赁路径把 `Q7` 改成 9000，切到自购路径看到的仍是自购路径原来的值；
- 切回租赁路径，`Q7` 恢复为 9000；
- 改答页底部「其他路径上保存的答案」列出当前路径之外已保存的值。

改答时若修改了前面的单选题，导致路径变化，旧路径上的字段不会再提交生效（页面会提示未保存），其答案仍保留在原路径下。

## 目录

```
app/
  engine.py     跳题推演、路径存储、表单变更计算（纯 Python，无框架依赖）
  importer.py   答卷 CSV / JSON 解析、问卷构建、名册 CSV 解析
  roster.py     名册推演：合格判断、入样顺序、锁定校验（纯 Python）
  storage.py    SQLite 持久化（批次、答卷、名册、锁定；单事务与快照读取）
  main.py       Flask 路由
  templates/    页面
  static/       样式
examples/       示例 CSV、JSON 与预览脚本
tests/          引擎、导入、名册规则、网页测试
```
